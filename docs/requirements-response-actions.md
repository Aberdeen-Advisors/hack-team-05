# Requirements: Response Action

The Requirements output in the UI gets a new column, "Response Action". This is the
controlled vocabulary for that column.

| Response Action | Meaning |
| --- | --- |
| Address | Explain how Aberdeen would meet this requirement; nothing needs to be produced now. |
| Provide Information | Supply specific requested information in the response. |
| Provide Attachment | A specific form, document, pricing file, etc. must accompany the proposal. |
| Acknowledge / Confirm | Explicitly confirm Aberdeen can comply with the condition. |
| Deliverable if Awarded | Something Aberdeen would actually produce during the engagement. |

output were dropped on purpose.
