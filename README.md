# hack-team-05

Aberdeen Hackathon 2026 team repository.

## The prompt

> A consulting firm receives an attractive RFP but has only seven days to respond, and its competitors are likely to submit similar credentials and generic approaches. The pursuit team needs to demonstrate that it understands the client's problem, not merely describe its capabilities. Build an AI-powered business development assistant designed to help teams rapidly create first drafts of proposals, pitch materials, and pursuit strategies. It ingests RFPs, client context, prior proposals, case studies, credentials, service offerings, and market research, then generates win themes, solution approach, staffing model, timeline, draft content, and differentiators. The tool could help Aberdeen respond faster and more consistently to growth opportunities.
